# 文字排版效果生成器

一个基于 HTML Canvas 的文字排版效果工具，用来快速生成漂浮文字、雨落文字、弹幕文字、图片轮廓文字等视觉效果，并导出 PNG 图片。

在线使用：
[https://shiemezz9.github.io/text-layout-generator/](https://shiemezz9.github.io/text-layout-generator/)

制作者：[@shiemezz](https://github.com/shiemezz9)

## 功能

- 中轴线两端漂浮：文字围绕横轴或竖轴分布，支持随机大小、旋转、模糊、色块和按输入顺序连线。
- 竖排雨落层次：按列生成竖排文字雨，支持列顺序、严格字数、模糊层次和中心位置调整。
- 横排弹幕模式：按行生成弹幕式文字层次，适合横向台词、短句和段落视觉。
- 泪水模糊：先排完整段文字，再在文本区域生成圆形羽化模糊区域，模拟墨迹、泪水或失焦效果。
- 立体漂浮：模拟文字向上或向下散开的空间感，支持 X/Y/Z 轴随机旋转。
- 图片轮廓框字：上传图片后提取图形边缘，用文字围绕图片轮廓排布。
- 图片填充字：根据上传图片的阈值遮罩，在图形内部按横排或竖排填充文字。
- 文字环形排版：沿圆周顺时针排列，长文本自动从外圈排到内圈；也可以每行输入一个段落，让段落沿射线从外向内排列，字号逐渐变小。
- 水面倒影：所有效果模式均可开启。水平面以下的原文字会被裁剪，倒影随距离逐渐模糊，并可调整水波纹密度。
- 随机颜色：所有效果模式都可选择一至五种颜色，按输入段落或按字随机上色；独立的颜色随机种子可重复生成同样的颜色分配。
- PNG 导出：支持高清导出、透明背景导出、右键保存和移动端长按保存。

## 使用方式

1. 打开在线页面或直接打开本仓库的 `index.html`。
2. 在文本框中输入要生成的文字。
3. 选择效果模式。
4. 调整字体、颜色、字号、模糊、分散程度、画布尺寸等参数。
5. 如果使用图片相关模式，上传图片并调整“图片阈值”来控制识别范围。
6. 点击“下载 PNG”导出图片。

桌面浏览器中，右侧预览始终显示在窗口内。在预览区域使用滚轮，也可以滚动左侧选项。

环形排版中，“沿圆周排列”可以调整字号、外圈半径、内圈半径、文字间距和圆圈间距；“按段落放射排列”以换行分段，可以调整最大字号、最小字号、内外圈半径和每段距离中心的随机度。距离中心的随机度会让每段文字整体沿放射线移动，字号和段内字间距保持不变。内圈半径以外圈半径的百分比表示，设为 0 时使用自动半径。放射排列勾选“反向”后，每段文字从内向外阅读，字号也从小到大。两种形式都支持随机字号幅度、随机模糊和随机种子，并按照输入顺序使用全部文字。相同随机种子和设置会生成相同排版。

环形排版相关滑杆支持更大的字号、间距、模糊和随机幅度。外圈半径最高为画布短边的 49%，以减少文字被画布边缘裁切。

在“字体颜色模式”中选择“随机颜色”，设置颜色数量和每种颜色，再选择“按段落”或“按字”。按段落时，每次换行代表一个段落，同一段使用一种颜色。颜色随机种子只调整配色，排版随机种子仍控制文字位置和其他随机效果。

开启“水面倒影”后，可调整水平面高度、倒影模糊程度和水波纹密度，也可开启“隐藏水平面”去掉水面细线。水平面高度从画布顶部起算。PNG 导出会保留倒影；复制 HTML 时会把倒影画面内嵌为图片，以保留模糊和波纹的完整效果。

撕裂模糊模式复制 HTML 时也会内嵌画面图片，保留逐字颜色和模糊效果。

## 图片模式说明

图片相关功能会读取上传图片的亮度、透明度和阈值信息：

- 对比清晰的黑白图、剪影图、透明 PNG 效果最好。
- 如果图形范围不准确，可以调节“图片阈值”。
- 图片轮廓框字更适合描边、外形、剪影边缘。
- 图片填充字更适合实心图形、标志、人物或物体剪影。

## 字体

工具内置若干适合不同风格的字体选项，包括：

- Noto Serif SC
- Noto Sans SC
- Noto Sans SC Black
- ZCOOL QingKe HuangYou
- ZCOOL KuaiLe
- DotGothic16

这些字体通过 Google Fonts 加载。字体本身遵循各自的开源或免费商用授权条款；导出作品的使用范围请以字体原始授权为准。
